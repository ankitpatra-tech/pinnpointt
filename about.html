ARCHITECTURAL RATIONALE

Why PinnPointt Exists

Sending a file to someone sitting next to you shouldn't take a detour through a corporate data center. PinnPointt fixes everyday file sharing with native WebRTC engineering.

TRADITIONAL CLOUD TRANSFER
  • Double Waiting: You wait 15 minutes to upload to a cloud server, then your receiver waits another 15 minutes to download.
  • Paywalls & 2 GB Caps: Free cloud services cut you off at 2 GB, throttle download speeds, or demand monthly credit card subscriptions.
  • Files Stored Remotely: Cloud providers store your sensitive documents and personal photos on their remote servers.
  • Ecosystem Silos: AirDrop only connects Apple devices; Quick Share is fragmented across vendor platforms.
PINNPOINTT ARCHITECTURE
  • Direct Device-to-Device: Data streams straight from your device to the other device across your Wi-Fi or direct peer link with zero cloud storage.
  • No File Size Limits: Share 50 MB or 50 GB. Smooth chunk streaming ensures your browser never freezes or crashes.
  • 100% Private & Temporary: Nothing is ever saved to any server. Once the transfer finishes, the connection closes and leaves no trace behind.
  • Universal Device Freedom: Instant compatibility across iPhone, Android, Mac, Windows, Linux, iPad, and Chromebooks right in the browser.

Universal Hardware Freedom

No more Apple-only or Android-only barriers. PinnPointt works seamlessly between an iPhone and a Windows PC, an Android phone and a MacBook, or a Linux desktop and an iPad. If a device has a browser, it works.

Zero Double-Waiting

Cloud drives force you to wait twice: 15 minutes to upload a 4 GB video to their server, then the other person waits another 15 minutes to download it. PinnPointt streams data live — as the sender reads the file, the receiver saves it.

Rock-Solid Large File Streaming

Traditional browser transfer tools attempt to load whole files into memory all at once, crashing tabs on files over 500 MB. PinnPointt uses smart OPFS chunk streaming to deliver multi-gigabyte files reliably.

SYSTEM CAPABILITIES

Designed to Be Simple & Fast

No complex setups, no tech jargon. Just open PinnPointt and start sharing.

30–80+ MB/s

4-Channel Parallel WebRTC

Dedicated pool of 4 negotiated binary data channels (pinnpointt-data-0..3) with round-robin lowest-buffered scheduling, saturating local 5GHz Wi-Fi at 30–80+ MB/s without pausing between reads.

8-State Engine

Instant Lossless Pause & Resume

Bidirectional pause and resume protocol backed by OPFS chunk checkpointing. Sender halts disk reads instantly; resume syncs the exact lowest unwritten chunk index on disk with zero duplicate bytes sent.

Live Mount

P2P Virtual Drive

Mount local files or full directory trees as a remote virtual drive. Peers browse remote folders, preview files via on-demand byte slicing, and selectively pull items without upfront bulk downloads.

Exif & GPS

In-Flight Privacy Shield

Automatic EXIF, GPS, and camera metadata stripping directly in memory before bytes leave your device. Losslessly removes location tags and timestamps with zero pixel recompression.

Zero-RAM OPFS

Zero-RAM Disk Streaming

12-byte binary framed chunks written directly to random-access byte positions via OPFS and File System Access, bypassing RAM constraints while Mobile Screen WakeLock keeps displays active.

Volatile RAM

Zero-Trace View & Live Clipboard

Ephemeral view mode renders confidential images directly into volatile HTML5 canvas memory with right-click saves blocked. Live universal clipboard syncs text, links, and code with one click.

Zero Backend

Hybrid Serverless Signaling

High-speed WebSocket relay backed by automatic 2,500ms fallback to 100% serverless P2P Nostr signaling. Functions seamlessly on pure static web hosting with zero backend server dependencies.

1-Second Pair

Instant Camera Pairing & E2EE Chat

Scan the on-screen QR code or enter a 6-letter room code to connect in seconds. Communicate through end-to-end encrypted (WebRTC DTLS) live chat while files transfer with SHA-256 verification.

DEVELOPMENT PHASES

The Path to Open Source & Global Launch

Our commitment is clear: PinnPointt will become 100% free and open-source software (FOSS) under the MIT License upon reaching its v1.0.0 Global Stable release.

NOTE Roadmap milestones, feature targets, and release timelines are subject to change based on community feedback, browser standard evolutions, and engineering priorities.
v0.0.1 – v0.0.57 beta Shipped & Live

Phase 1: Core Foundation & Web App

Direct device-to-device streaming, pairing, and visual experience.

  • 4-Channel parallel WebRTC multi-stream engine (30–80+ MB/s on local 5GHz Wi-Fi).
  • Instant, lossless Pause, Byte-Offset Resume & Cancel protocol with OPFS disk checkpointing.
  • 12-Byte zero-overhead binary framing with random-access OPFS and direct disk writes.
  • P2P Virtual Drive: mount remote directories, on-demand byte-slice previews & selective file pulls.
  • In-Flight Privacy Shield: in-memory EXIF, GPS & metadata stripping before DataChannel transmission.
  • Zero-RAM disk streaming via OPFS & FileSystemAccess with active Mobile Screen WakeLock.
  • Ephemeral Zero-Trace View mode via volatile canvas memory & live universal clipboard sync.
  • Hybrid signaling engine: primary WebSocket relay with 2,500ms serverless Nostr P2P fallback.
  • Instant camera pairing via dynamic on-screen QR codes & 6-letter room pairing.
  • End-to-End Encrypted (E2EE) real-time live chat over WebRTC DTLS.
  • Client-side file safety triage, executable quarantining & SHA-256 pre-verification.
v0.0.6 – v0.0.9 beta Q1 2027 • In Progress

Phase 2: Enhanced Sharing Capabilities

Expanding file handling capabilities and peer discovery resilience.

  • Whole folder directory streaming preserving subfolder hierarchies.
  • Automatic local network discovery without requiring internet signaling.
  • Resumable transfer checkpoints if network drops temporarily.
  • Multi-device broadcast (send one file to multiple devices at once).
v1.0.0 Global Stable Open-Source Launch

Phase 3: Global Launch & 100% Open Source Release

PinnPointt will transition into a fully public, decentralized community utility.

  • Public GitHub Repository: Complete source code released under the permissive MIT License.
  • 1-Command Docker Node: Easy self-hosting for universities, teams, and private networks.
  • Decentralized Discovery: Direct peer discovery with zero dependence on central servers.
  • Community Contributor Program: Bounties for translations, accessibility, and platform optimizations.

Hey everyone,

I built PinnPointt because sharing a file between two devices in 2026 is still surprisingly frustrating.

Think about what usually happens: you want to send a video from your phone to your laptop, or share photos with a friend sitting next to you who has a different phone. You're forced to upload it to a cloud drive, wait forever, hit a 2 GB storage limit, or sign up for an account you didn't want. And while you wait, your private files are saved on someone else's servers.

I wanted something that just works: open the page, point your camera, and send the file straight across at full speed. No logins, no cloud storage, and no size limits.
